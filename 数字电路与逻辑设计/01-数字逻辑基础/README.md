## 知识点介绍

- 数字电路用 `0` 和 `1` 表示信号的两种对立状态，逻辑门是对二进制信号进行逻辑运算的基本单元。
- 七种常见基本逻辑门（与、或、非、与非、或非、异或、同或）已整理，详见 [常见基本逻辑门](./常见基本逻辑门.md)。

## 易错点

- 逻辑或中 $1+1=1$，与普通二进制算术加法（$1+1=10$）不同。
- 异或与同或的输出正好相反：异或是输入不同得 1，同或是输入相同得 1。
