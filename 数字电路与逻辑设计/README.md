# 数字电路与逻辑设计

本目录是《数字电路与逻辑设计》的知识库，记录从零开始学习数字电路的过程。

学习主线：数字逻辑基础 → 逻辑代数 → 组合逻辑电路 → 时序逻辑电路 → 存储器与数字系统，配合实验仿真与错题复盘。目标是把数电知识与计算机组成原理、单片机以及人工智能相关硬件联系起来，建立从逻辑门到完整计算机系统的自底向上理解。

5. **存储器与数字系统**：存储器基础；数字电路与计算机组成原理
